Checkpoint quiz

Same history, six memories

Six memory strategies for AI applications compete to see which remembers best. Each contestant replays the chats in order and keeps whatever its strategy keeps. After sessions 5, 10, 15 and 20, the assistant is quizzed using only that memory, and a judge grades each answer against the answer key. The maps show what each memory held about each fact after every session.
